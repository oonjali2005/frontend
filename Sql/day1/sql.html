Database Concepts

RDBMS

RDBMS (Relational Database Management System) is software that stores and manages data in tables with rows and columns.

SQL

SQL (Structured Query Language) is used to create, retrieve, update, and delete data from a database.

MySQL

MySQL is an open-source Relational Database Management System used to manage databases.

MySQLi

MySQLi is a PHP extension used to connect PHP applications with MySQL databases.

PostgreSQL (PG)

PostgreSQL is an advanced open-source relational database system known for reliability and performance.

Oracle

Oracle is a commercial RDBMS widely used in large organizations for enterprise applications.

Server

A server is a computer or software that provides services and resources to other computers over a network.

XAMPP

XAMPP is a local server package that includes Apache, MySQL/MariaDB, PHP, and Perl.

WAMP

WAMP is a Windows-based local server package containing Apache, MySQL, and PHP.

GUI

GUI (Graphical User Interface) allows users to interact with software using windows, icons, buttons, and menus.

MySQL Workbench 8

MySQL Workbench 8 is a graphical tool used to design databases, execute SQL queries, and manage MySQL servers.
