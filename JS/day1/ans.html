1. What is a Variable?

A variable is a container used to store data values in a program.

What is Declaration?

Declaration means creating a variable using a keyword (var, let, or const).

3. What is Initialization?

Initialization means assigning a value to a variable.

4. Three Types of Keywords Used for Variables

JavaScript provides three keywords to create variables:

  • var
  • let
  • const

5. What are Printing Statements?

Printing statements are used to display output.
