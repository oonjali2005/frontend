Frontend Development Concepts

1. What is DOM?

DOM (Document Object Model) allows JavaScript to access, change, add, or remove HTML elements dynamically.

Example:

Hello World

2. What is React?

React is a JavaScript library used to create fast, interactive, and reusable user interfaces using components.

Example:

function App(){ return <h1>Hello React</h1>; }

3. What are Components?

Components are small, reusable parts of a user interface. They help divide a large application into manageable sections.

Example:

Navbar Component
Product Component
Footer Component

4. What are Functions?

A function is a reusable block of code that performs a specific task.

JavaScript Example:

function greet(){
  console.log("Hello");
}
